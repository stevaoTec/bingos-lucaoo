🚀 Passo a Passo: Como pegar o código no Firebase (2 minutos)
  1. Acesse console.firebase.google.com, clique em Criar um projeto (qualquer nome, ex: bingo-lucao).
  2. No menu lateral esquerdo, clique em Criação (Build) → Firestore Database → Criar banco de dados e escolha Iniciar no modo de teste (Test mode).
  3. No menu lateral esquerdo, clique em Criação (Build) → Authentication → Vamos começar → Método de login → Anônimo → Ativar e Salvar.
  4. Na tela inicial do projeto, clique no ícone Web </>, dê um apelido e copie o bloco const firebaseConfig = { ... }.
